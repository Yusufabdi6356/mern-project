# Finance Tracker

Keep track of your income and expenses and see where your money goes every month.

- `backend` - Express, MongoDB, JWT, Zod, Cloudinary, Swagger docs at `/docs`
- `frontend` - React, Vite, Tailwind, shadcn/ui, TanStack Query, Zustand

## Getting started

Copy `backend/.env.example` to `backend/.env` and add your values, then:

```bash
npm install
npm run install-all
npm run dev
```

The frontend runs on http://localhost:5173 and the API on http://localhost:3000.
